# 先备 · READY —— 家庭灾害预防终端

> 面向普通家庭的**个人备灾情报应用**：填一份家庭安全画像，自动生成专属备灾清单，逐项打勾推进「备灾指数」，并配套灾中行动指南、装备知识库与备灾小游戏。

**🌐 在线体验：** https://xianbei-prep-fc966d31.eazo.dev

---

## 一、这是什么

灾害来临前，多数家庭根本不知道「该准备什么、准备多少」。**先备** 把这件事变简单：

1. **填画像** —— 城市、住宅类型、家庭成员（老人 / 儿童 / 宠物 / 慢病等）。
2. **出清单** —— 纯规则匹配，生成你家专属的 BOB（应急包）备灾清单，并按人数自动配量。
3. **推进度** —— 逐项打勾，实时计算「备灾指数」与成长等级 / 称号。
4. **会应对** —— 灾中行动指南（DROP / COVER / HOLD ON）、紧急拨号、灾后恢复清单。
5. **学知识** —— 装备知识库 + 备灾误区判断小游戏，边玩边学。

支持灾害：入室抢劫 / 燃气泄漏 / 火灾 / 地震 / 洪水 / 台风。

---

## 二、核心功能

底部导航为 3 个 Tab：**首页 / 背包 / 社区**；「灾中行动指南」「备灾小游戏」为栈页入口，「我的」从侧边栏进入。

| 模块 | 说明 |
|---|---|
| 🏠 首页（Tab） | 备灾指数总览、待补充清单、紧急入口 |
| 🎒 背包 / 清单（Tab） | 个性化清单三分组，可勾选、可自定义、按人数配量 |
| 🛒 社区商城（Tab） | 备灾好物口碑流、一键打包配齐、模拟下单 |
| 🧭 灾中行动指南（栈页） | 分灾种大字号处置步骤 + 紧急拨号 + 灾后恢复 |
| 🎮 备灾小游戏（栈页） | 判断题答对得成长值，**题库支持后台云端修改、免重新部署** |
| 👤 我的（侧边栏进入） | 成长数据、等级称号、评估入口 |

---

## 三、技术栈

- **框架**：Next.js 16（App Router）+ React 19 + TypeScript
- **样式**：Tailwind CSS v4（工业数据终端 / 报刊应急情报视觉风格）
- **数据**：PostgreSQL + Drizzle ORM（评价 / 点赞 / 题库等持久化）
- **运行时**：Bun
- **平台**：Eazo（内置认证 / 数据库 / 部署）

视觉语言：冷白纸底 + 警示橙 + 略发煎墨色，硬边细线、超大数字、SYS 编号数据模块，轻度做旧质感。

---

## 四、本地运行

```bash
# 安装依赖
bun install

# 启动开发服务器
bun dev
# 打开 http://localhost:3000
```

> 数据库相关能力需要配置 `DATABASE_URL` 环境变量；未配置时静态内容与前端交互仍可正常体验。

## 五、目录结构

```
src/
├─ app/                 # 页面路由（首页 / bag / community / cart / guide / quiz / me …）
├─ components/          # 界面组件（screens / shell 共享 UI）
├─ lib/prep/            # 领域数据与规则（清单规则、装备库、行动指南、题库）
├─ lib/db/              # 数据库 schema 与查询（Drizzle）
└─ stores/              # 前端状态（备灾进度、成长值等）
```
